# 文献日报

[简体中文](README.md) | [English](README.en.md)

Windows 桌面文献筛选工具：按研究方向检索 OpenAlex / Crossref 元数据，筛选论文并生成可交互的 HTML 日报、Excel 和 JSON。GUI 由 PySide6 构建，HTML 日报直接嵌入 GUI 的浏览器标签页。

> **重要说明：** 本工具使用 OpenAlex 和 Crossref 的公开元数据接口检索论文。校园网或出版社登录只影响你打开论文网页的权限，不会让程序自动下载出版社付费全文。数据库是否提供摘要取决于其元数据记录；缺失的英文摘要无法通过翻译服务补出来。

## 直接运行打包版

默认文件夹版从 `dist\文献日报\` 启动 `文献日报.exe`，需要连同 `_internal` 目录一起保留。

也可以运行 `dist\文献日报单文件版\文献日报.exe`。该版本本身不需要 `_internal` 文件夹；建议和 `config.yaml` 一起移动，以保留检索方向等配置。运行时会在 EXE 同一目录创建缓存和结果文件夹，因此请放在有写入权限的位置；不要放在只读目录。

- 第一次使用：在 GUI 的「检索与设置」填写门户、翻译及邮箱配置，然后保存。
- 自定义检索：先选择「自定义方向」，再在随之显示的输入区填写关键词；已有方向不受这些词影响。
- 立即检索：默认最近 **3 天**，也可选 **7 天**或 **15 天**，并按全部主题或单个方向检索。
- 查看结果：在「检索结果」页筛选论文；在「HTML 日报」页查看完整交互式日报。
- 「关于软件」按钮显示版本、作者、邮箱和数据源信息。
- 日报、缓存、状态、日志和 `secrets.yaml` 都保存在 EXE 所在文件夹。请将程序放在当前 Windows 用户有写入权限的位置，例如文档目录；不要放在 `Program Files` 等受保护目录。
- 门户密码、翻译 API 密钥和 SMTP 授权码使用当前 Windows 用户的 DPAPI 加密。迁移到其他 Windows 用户或电脑时，需要重新填写这些凭据。

## 从源代码运行

没有打包版时，也可以从源码运行：

```bat
python -m pip install -r requirements.txt
python gui.py
```

命令行运行：

```bat
python run_daily.py --days 3 --topic COF
python run_daily.py --days 7 --topic OLED --no-translate
python run_daily.py --days 15
```

常用参数：

| 参数 | 说明 |
|---|---|
| `--days N` | 检索最近 N 天 |
| `--topic 名称` | 只检索名称匹配的方向 |
| `--top N` | 限制报告论文数量 |
| `--include-reported` | 包含过去日报记录过的论文 |
| `--no-translate` | 本次关闭翻译 |
| `--no-open` | 生成日报后不自动打开 |
| `--email` | 本次运行后尝试发送邮件 |

结果保存在 `out\daily\` 和 `out\data\`。`latest.html` 是最新 HTML 日报。

## 自行打包 EXE

项目根目录提供 `文献.ico` 和 `build_exe.bat`。双击脚本，或在命令行执行：

```bat
build_exe.bat
```

脚本会安装构建依赖并使用 `文献.ico` 生成两个带图标的版本：

```text
dist\文献日报\文献日报.exe
dist\文献日报单文件版\文献日报.exe
```

文件夹版需要连同 `_internal` 目录分发；单文件版不需要该目录，但启动时会先解压运行组件，因此 EXE 更大、首次启动更慢。构建脚本不会把本机的 `secrets.yaml` 打包进去；请勿把包含个人凭据的配置或生成结果公开分享。
重复打包会更新 EXE 和运行组件，但保留发布目录中已有的配置、密钥和检索数据。

## 检索来源与门户设置

- 检索来源：OpenAlex，额度不足或请求失败时回退到 Crossref。
- 出版社链接：报告提供 DOI / 出版社页面链接；访问付费全文仍需机构订阅、校园网或 VPN。
- 摘要：优先使用 OpenAlex / Crossref 提供的元数据，程序会尝试从 Crossref 补齐。个别论文没有摘要记录时会显示缺失提示。
- 门户登录：GUI 可填写校园网或数据库门户 URL、账号和密码，并选择尝试自动登录。自动登录只针对当前代码支持的门户流程；它不等于出版社网页采集，也不保证所有学校登录页面都兼容。

如果门户不在支持范围内，可以留空或自行填写门户信息；未能登录时仍会尝试用 OpenAlex / Crossref 生成报告。

## 检索方向与时间范围

GUI 的检索方向和时间范围同样用于立即检索和每日计划。选择单个主题（例如 COF）时，该次日报的论文、主题标签、统计及 HTML 过滤器会限定为所选主题。选择「全部主题」时使用 `config.yaml` 中配置的所有方向。

检索方向下拉框包含固定的「自定义方向」。只有选择它时，下面才显示自定义关键词输入区；选择 COF 等已有方向不会混入自定义词。将关键词逐行填写（也可用逗号或分号分隔），内部主题标签会由关键词自动组合，例如 `Perovskite, COF` 显示为 `Perovskite COF`；多个词按 OR 关系检索。保存后，自定义关键词仅用于当前选中的自定义方向，结果详情和 HTML 日报会显示实际关键词。检索结果主要受 OpenAlex / Crossref 元数据覆盖影响。

没有翻译 API 时，检索词不会自动翻译。中文关键词会作为原词提交给 OpenAlex / Crossref，但这两个来源的记录通常以英文为主，因此只填中文可能漏掉大量论文。建议在同一组同时填入中文词和对应英文词/同义词；翻译服务设置只用于翻译论文标题和摘要，不会把检索词自动翻译。

默认窗口为最近 3 天，支持 3、7、15 天。OpenAlex / Crossref 的收录可能有延迟，检索窗口并不代表每篇论文都会被及时收录；更长时间窗口也会增加请求量。已报告记录用于每日去重；GUI 的“立即检索时包含此前已报告的文献”选项可用于重新查看历史窗口。

## 翻译设置

GUI 提供以下翻译范围：

- **仅标题**
- **仅摘要**
- **标题和摘要**（默认）

日报在存在对应译文时会同时显示中文译文和英文原文。摘要翻译字符上限可在 GUI 调整；设为 0 表示不翻译摘要。没有英文摘要时，翻译服务无内容可翻译。

可选后端为 `auto`、有道、MyMemory、DeepSeek、智谱和百度。联网翻译会将待翻译文本发送给所选服务商；请自行确认服务商的隐私条款、费用和配额。翻译结果会缓存在 `cache\translate.json`。

X-MOL 页面访问可能触发人机验证；本项目没有接入其官方 API，也不会尝试绕过验证。若有官方提供且已获授权的 API，可另行评估对接。

## 邮件设置

邮件由你配置的 **发件邮箱 SMTP 账户**发送，不是由本工具代发。GUI 至少需要：

1. SMTP 服务器和端口（例如 QQ 邮箱 `smtp.qq.com:465`，具体参数以邮箱服务商说明为准）；
2. 发件邮箱地址；
3. 服务商生成的 SMTP 授权码（通常不是网页登录密码）；
4. 收件邮箱地址。

若只发给自己，收件邮箱可以与发件邮箱相同。填写完后启用「筛选后自动发送邮件」并保存；只有当次运行有符合发送条件的结果时才会发信。建议先确认邮箱已开启 SMTP 服务并取得授权码。

## 每日定时任务

在 GUI 选择主题、时间范围和运行时间，然后点击「设置每日任务」。Windows 任务计划程序会以当前账户启动程序；日志写入 `logs\run.log`。电脑需要在设定时间开机并具备网络连接。

更换 EXE 文件夹位置后，请在 GUI 删除旧任务并重新设置。命令行取消任务：

```bat
schtasks /Delete /TN "LitDaily" /F
```

## 配置与数据文件

| 路径 | 用途 |
|---|---|
| `config.yaml` | 研究方向、检索、评分、翻译和输出等基础配置 |
| `secrets.yaml` | 本机私密配置；通常由 GUI 写入，不要分享 |
| `secrets.example.yaml` | 手动配置参考模板，不包含真实凭据 |
| `state\state.json` | 已报告论文、收藏反馈及去重状态 |
| `state\gui_settings.json` | GUI 的主题、日期范围、计划任务和自定义关键词 |
| `cache\` | 论文元数据与翻译缓存 |
| `out\daily\` | HTML 日报 |
| `out\data\` | JSON 与 Excel 报告 |
| `logs\` | 运行日志 |

删除状态文件会影响去重，可能导致旧论文再次出现在报告中。删除翻译缓存会令已有文本下次重新翻译。

## 故障排查

- **OpenAlex 返回 429 / budget 错误：** 额度耗尽或限流时程序尝试回退到 Crossref；也可申请 OpenAlex API Key 并在配置中填写。
- **没有摘要：** 检查元数据源是否提供该论文摘要。门户登录不能保证出版社摘要会被 API 收录。
- **Windows 任务栏图标未更新：** 源码已设置窗口图标和 Windows 应用 ID；需要重新打包后新版本才会生效。已固定到任务栏的旧快捷方式可取消固定，再从新版本 EXE 启动/固定。
- **翻译为空或失败：** 查看运行日志，确认翻译开关、后端、密钥、网络及服务商额度；也可以关闭翻译继续生成报告。
- **页面/邮件顶部提示站点不可达：** 新版本不再在 HTML 日报或邮件里显示预检警告；详细诊断仍保留在运行日志中。
- **计划任务未运行：** 确认 Windows 计划任务状态、EXE 文件夹可写、电脑在计划时间开机，以及该用户仍有权限解密 DPAPI 凭据。
- **EXE 启动失败：** 保留整个发布文件夹；不要仅复制 EXE。若是自行构建，请重新运行 `build_exe.bat` 并查看构建输出。
